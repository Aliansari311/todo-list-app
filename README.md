# Todo List App ✅

A simple and user-friendly **Todo List Web Application** built with **Python Flask**.
This application helps users manage their daily tasks with a clean and easy-to-use interface.

## 🚀 Live Demo

https://aliansari.pythonanywhere.com

## 📌 Features

* ✅ Add new tasks
* ✅ View tasks
* ✅ Manage daily todo items
* ✅ Simple and clean UI
* ✅ Flask-based backend
* ✅ Responsive design

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* Jinja2
* Git & GitHub
* PythonAnywhere (Deployment)

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Aliansari311/todo-list-app.git
```

### Navigate to Project Folder

```bash
cd todo-list-app
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

Open in browser:

```text
http://127.0.0.1:5000
```
